# 金苹果护甲四件套 · 1.5.0

适用 Minecraft Java 1.20.1 / Forge 47.x。已有装备无需重新合成，安装新版后自动使用新属性。

| 部位 | 护甲值 | 韧性 |
| --- | ---: | ---: |
| 头盔 | 3 | 2 |
| 胸甲 | 8 | 2 |
| 护腿 | 6 | 2 |
| 靴子 | 3 | 2 |
| 全套 | 20 | 8 |

防御与原版下界合金相同，韧性与原版钻石相同。耐久、击退抗性、合成表与边缘绿叶外观沿用原设置。

四件对应金苹果护甲必须全部穿在正确护甲栏，才会激活：

- 生命上限 +6（3 颗心）；没有其他生命加成时为 26 点，即 13 颗心。穿戴不会立即补满新增的生命。
- 持续生命恢复 I，沿用原版治疗节奏。不会降低更高级的生命恢复，也不会覆盖无限时长的恢复效果。
- 脱下、损坏或替换任意一件后，生命上限加成立即移除（下一服务器 tick），当前生命超过新上限时会被限制至新上限。
- 套装生命恢复停止续效，剩余效果最多 3 秒消退；保留药水、金苹果、剑等其他来源的生命恢复。

服务端使用固定 UUID 的临时属性修饰符，重复穿脱不会叠加，不修改基础生命上限，不永久写入玩家属性。两种语言均有护甲套装提示。

开发验证（在 gas_mod 下执行，使用项目 JDK 17）：

```powershell
& './gradlew.bat' -I scripts/build_with_mirror.gradle -I scripts/render_smoke.gradle -PgasSmoke=armor runClient --offline --console=plain
```

测试创建独立平坦世界，关闭自然回血，在真实服务端 tick 中检查属性、治疗、穿脱、混搭、客户端同步与药水共存。结果和截图在 `art/armor_set/runtime/`，测试源代码不进入发布 JAR。
